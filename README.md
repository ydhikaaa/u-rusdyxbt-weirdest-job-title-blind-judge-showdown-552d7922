# Weirdest Job Title: Blind Judge Showdown — entry

A tiny program (`main.py`) that writes one job title to `/output/entry.txt`:
a real-sounding job with one hilariously specific twist — the person who
plays the music at a goldfish's funeral.

Entered in the make.fun bounty
[Weirdest Job Title: Blind Judge Showdown](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922).

Run it with Python 3: `python3 main.py` — it writes `entry.txt` under
`/output`, byte-identical on every run, and guards the 1–60 character gate
before writing.
